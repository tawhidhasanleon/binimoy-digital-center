# BINIMOY DIGITAL CENTER Website

Responsive Bangla/English static website for GitHub + Vercel.

## Included
- Original supplied logo: `assets/binimoy-logo.png`
- Responsive Home, Services, Offers, About and Contact sections
- Phone and WhatsApp: 01710052008
- Google Maps share link and directions using coordinates 22.3145744, 90.1372151
- No build step required

## Deploy
1. Extract this ZIP.
2. Upload all files and folders to a new GitHub repository.
3. Import that repository in Vercel (Add New → Project).
4. Choose Framework Preset: Other. No build command is required.
5. Deploy.

## Important
This package is the public-facing website only. A secure admin dashboard, customer database, payments, and authentication are not included. Those require a backend such as Supabase or Firebase with server-side access controls. Never store passwords or secret API keys in front-end JavaScript.
